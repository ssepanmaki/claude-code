## Overview

Claude Code's GrowthBook system can connect to a custom GrowthBook server through environment variables, enabling remote feature flag control.

- **When configured**: connects to your GrowthBook instance and fetches and caches feature values
- **When not configured**: every feature read returns the default in the code directly, with zero network requests

## Environment variables

| Variable | Required | Description |
|---|---|---|
| `CLAUDE_GB_ADAPTER_URL` | Yes | GrowthBook API address, such as `https://gb.example.com/` |
| `CLAUDE_GB_ADAPTER_KEY` | Yes | GrowthBook SDK Client Key, such as `sdk-xxxxx` |

Adapter mode is enabled when both variables are set; otherwise GrowthBook is skipped entirely.

## Usage

### Basic usage

```bash
CLAUDE_GB_ADAPTER_URL=https://gb.example.com/ \
CLAUDE_GB_ADAPTER_KEY=sdk-abc123 \
bun run dev
```

### Without GrowthBook (the default)

```bash
bun run dev
# Every getFeatureValue_CACHED_MAY_BE_STALE("xxx", defaultValue) returns defaultValue directly
```

## GrowthBook server configuration

### Steps

1. **Deploy the GrowthBook server** (self-hosted with Docker, or the Cloud edition)
2. **Create an Environment** (such as `production`)
3. **Create an SDK Connection** to get the SDK Key (that is, `CLAUDE_GB_ADAPTER_KEY`)
4. **Add Features as needed**; the keys and types are in the lists below

### Core principles

- **It runs fine with no features configured**: every call in the code provides a default value
- Only create the features you want to control remotely; the rest use the code defaults
- Once a feature is configured on GrowthBook, its value overrides the default in the code

## Read priority chain

Each feature's value is resolved in the following order; the first hit wins:

```
1. The CLAUDE_INTERNAL_FC_OVERRIDES environment variable (JSON object override)
   ↓ miss
2. growthBookOverrides config (~/.claude.json, ant builds only)
   ↓ miss
3. In-memory cache (remoteEvalFeatureValues, fetched from the server by this process)
   ↓ miss
4. Disk cache (cachedGrowthBookFeatures in ~/.claude.json)
   ↓ miss
5. The defaultValue argument in the code
```

## Caching and refresh

| Mechanism | Description |
|---|---|
| **Disk cache** | The `cachedGrowthBookFeatures` field of `~/.claude.json`, persisted across processes |
| **Periodic refresh** | Fetches the latest values from the server every 6 hours (`setInterval` + `unref`) |
| **Init timeout** | The first connection times out after 5 seconds, then the disk cache or defaults are used |
| **Auth change** | The client is destroyed and rebuilt automatically on login/logout |

## Implementation details

Three changes across 2 files:

1. **`src/constants/keys.ts`**: `getGrowthBookClientKey()` reads `CLAUDE_GB_ADAPTER_KEY` first
2. **`src/services/analytics/growthbook.ts`**: `isGrowthBookEnabled()` is enabled directly in adapter mode
3. **`src/services/analytics/growthbook.ts`**: the base URL prefers `CLAUDE_GB_ADAPTER_URL`

None of the 130+ calling files needed changes.
