## What feature() is

Claude Code uses the `bun:bundle` module of the Bun bundler for compile-time feature gating:

```typescript
// Usage in the source (src/tools.ts and others)
import { feature } from 'bun:bundle'

const SleepTool = feature('PROACTIVE') || feature('KAIROS')
  ? require('@claude-code-best/builtin-tools/tools/SleepTool/SleepTool.js').SleepTool
  : null
```

In Anthropic's internal builds, `feature()` is evaluated at bundle time: code that returns `true` is kept, and code that returns `false` is removed entirely by **Dead Code Elimination (DCE)**.

In our decompiled version, `feature` is imported from `bun:bundle` (declared in `src/types/internal-modules.d.ts`) and always returns `false` at runtime:

```typescript
// src/types/internal-modules.d.ts
declare module 'bun:bundle' {
  export function feature(name: string): boolean;
}
```

This means the code behind all 88+ feature flags **never runs at runtime**, but it is fully preserved and can be read and analyzed.

## Typical patterns in the code

Feature flags are used in three main patterns:

### Pattern 1: load a tool conditionally

```typescript
// src/tools.ts — the most common pattern
const MonitorTool = feature('MONITOR_TOOL')
  ? require('@claude-code-best/builtin-tools/tools/MonitorTool/MonitorTool.js').MonitorTool
  : null
```

When the flag is `false`, the `require()` call is removed by DCE and the tool never appears in the available tool list.

### Pattern 2: register a command conditionally

```typescript
// src/commands.ts — registering a slash command
if (feature('VOICE_MODE')) {
  commands.push({ name: 'voice', description: '...' })
}
```

### Pattern 3: enable an API feature conditionally

```typescript
// src/constants/betas.ts — controls the beta header sent to the API
export const AFK_MODE_BETA_HEADER = feature('TRANSCRIPT_CLASSIFIER')
  ? 'afk-mode-2026-01-31'
  : ''
```

<Note>
Because `feature()` is evaluated at build time, code removed by DCE does not add to the final bundle size. In the decompiled version all of that code is kept, which is exactly why a full analysis is possible.
</Note>

## Interesting findings

- **The KAIROS family** is the largest: 6 related flags control everything from core functionality to push notifications
- **ABLATION_BASELINE** is for "scientific control experiments": it turns off thinking, compaction, auto-memory and other advanced features to measure the baseline performance of bare API calls
- **BUDDY** is an AI mascot/sprite system, fully implemented under `src/buddy/`
- **ULTRAPLAN** and **ULTRATHINK** hint at reasoning modes more advanced than the current extended thinking
