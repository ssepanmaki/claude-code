## Overview

Buddy is Claude Code's built-in virtual pet system. In the REPL, the `/buddy` command hatches a randomly generated pet companion that appears next to the input box and keeps you company while you code.

> Feature Flag: `FEATURE_BUDDY=1`

## How to enable

```bash
FEATURE_BUDDY=1 bun run dev
```

Hatching window: when started between April 1 and 7, 2026, a rainbow-colored `/buddy` hint is shown at the top of the REPL. After April 7 the command still works but is no longer prompted automatically.

## Commands

| Command | Description |
|---|---|
| `/buddy` | Show the current pet's info and stats |
| `/buddy hatch` | Hatch a new pet (first use) |
| `/buddy rehatch` | Regenerate the pet randomly (replaces the existing one) |
| `/buddy pet` | Pet your pet, triggering a heart animation |
| `/buddy mute` | Mute the pet (hide it) |
| `/buddy unmute` | Unmute |

### Rarity

| Rarity | Stars | Weight |
|---|---|---|
| Common | ★ | 60% |
| Uncommon | ★★ | 25% |
| Rare | ★★★ | 10% |
| Epic | ★★★★ | 4% |
| Legendary | ★★★★★ | 1% |

Hatching is decided randomly from a seed, with a very small chance of a Shiny variant.

### Stats

Each pet has 5 stats (0-100):

- **DEBUGGING** — debugging skill
- **PATIENCE** — level of patience
- **CHAOS** — chaos index
- **WISDOM** — wisdom
- **SNARK** — snarkiness

### Appearance

Each pet also gets random cosmetic accessories:

- **Eyes**: `·` `✦` `×` `◉` `@` `°`
- **Hat**: none, crown, tophat, propeller, halo, wizard, beanie, tinyduck

## Data storage

Pet info is stored in the `companion` field of `~/.claude.json`. A pet's appearance attributes (species, rarity, stats, etc.) are generated deterministically from a hash of the user ID, so rarity cannot be tampered with by editing the config file.
